# electronic-music-RSS-starter-kit
I wanted to put together a little starter kit of RSS feeds, not just from blogs, but from newsletters, YouTube, social media, and other sources. I needed a place to house it, so I uploaded the file here. I generally use a combination of [Feedly]([url](https://feedly.com/)) and [Reeder]([url](https://reederapp.com)) for RSS subscriptions, but for this little project, I used [feedland.com](https://feedland.com) to collect and categorize the various RSS feeds. I may add to this over time. To use this set of recommended subscriptions, just download the [xml file]([url](https://github.com/disquiet/electronic-music-RSS-starter-kit/blob/main/electronic-music-rsss-starter-opml.xml)) and import it into the RSS reader of your choice.
